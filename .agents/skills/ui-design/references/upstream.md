The Phat adaptation rewrites purpose-specific composition, concrete direction,
type/layout craft, evidence-first critique, and refinement within the existing
parent-owned workflow. Changed material lives in `ui-design/SKILL.md`,
`references/design-craft.md`, `references/visual-critique.md`,
`references/refinement-playbook.md`, `references/interface-quality.md`,
`references/motion-and-variants.md`, and `references/design-system.md`.
The local HTML helper and its tests are original Phat implementation; it does
not reuse Impeccable's detector code or claim its coverage. The parent
integration and discovery notes are Phat-specific guidance.

This is not an installed or synchronized Impeccable distribution. It imports no
launcher, binary, upstream detector, hook, command dispatcher, mandatory setup interview,
PRODUCT.md/DESIGN.md persistence, asset-generation gate, or extra finish agent.
Use Phat's existing sources, permissions, file boundaries, and verification.
Explicit user choices override aesthetic defaults; upstream absolute styling
bans are not adopted. No native-platform reference material was adapted.
