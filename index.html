The method

Research is a boundary, not a detour.

Local requirements, accepted specs, and explicit decisions stay authoritative. Public docs only enter when a missing Phat-specific fact could change the next question.

01

Read what is already known

Start with AGENTS.md, context, requirements, and the decisions already made.

↘
02

Check only when it matters

If current Phat guidance changes the decision, discover it through /llms.txt, /search, or /docs.

↘
03

Leave the source attached

Record the URL, title, access date, and the exact claim the published material supports.

↘

Guardrails

Useful research has
edges.

01 / Authority

Project truth stays closest to the project.

Requirements, specs, ADRs, and explicit decisions remain the source of truth when public guidance disagrees.

02 / Attribution

Every material claim gets a receipt.

URL, title or identifier, access date, and supported claim keep research inspectable later.

03 / Restraint

Unknown is a valid result.

If the site is unavailable or the evidence is indirect, the gap stays open instead of becoming invented certainty.
