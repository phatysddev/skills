02 / THE TOOLKIT

19 SKILLS. ONE CONNECTED SYSTEM.

Small skills.
A complete workflow.

เลือกใช้ skill ที่ตรงกับงาน
หรือเริ่มที่ $ask-workflow
เพื่อหาขั้นตอนถัดไปของโปรเจกต์

/

01

ask-workflow

Core workflow

ให้ agent อ่านสถานะโปรเจกต์และแนะนำขั้นตอนถัดไปเพียงขั้นตอนเดียว

↗ 02

grill-workflow

Core workflow

ถามให้ชัดเรื่องปัญหา ขอบเขต กฎธุรกิจ และข้อจำกัด ก่อนเขียน spec

↗ 03

grill-design

Core workflow

บันทึกทิศทาง UI ที่ตกลงร่วมกัน เพื่อให้ขั้นตอนออกแบบใช้ข้อมูลชุดเดียวกัน

↗ 04

setup-project

Core workflow

จัดทำบริบทโปรเจกต์ เอกสารนำทาง และนโยบายการตรวจสอบงาน

↗ 05

write-spec

Core workflow

เขียน behavioral specification ที่มีขอบเขตและ acceptance criteria ชัดเจน

↗ 06

to-tasks

Core workflow

แยก spec ที่พร้อมแล้วเป็นงานย่อยที่ตรวจสอบได้ พร้อมลำดับ dependency

↗ 07

implement-task

Core workflow

ทำงานหนึ่ง task ให้ครบขอบเขต พร้อมหลักฐานตรวจสอบตามนโยบายโปรเจกต์

↗ 08

auto-implement

Core workflow

ตรวจ blockers ทั้งชุดก่อน แล้วทำ task ตาม dependency ทีละงาน

↗ 09

code-review

Core workflow

ตรวจ implementation เทียบกับ spec และ acceptance criteria ก่อนตัดสินว่า done

↗ 10

code-to-context

Brownfield

สร้างบริบทจากโค้ดพร้อมแหล่งอ้างอิง โดยรักษา context ที่เขียนไว้แล้ว

↗ 11

compact-context

Utilities

ย่อ handoff ชั่วคราวโดยรักษาข้อสรุป ข้อจำกัด และคำถามที่ยังเปิดอยู่

↗ 12

ui-design

Utilities

ช่วยจัดองค์ประกอบ UI ภายในงาน prototype หรือ implementation ที่อนุญาต

↗ 13

debug-task

Utilities

ทำ reproduction และทดสอบสมมติฐานเพื่อหาสาเหตุ โดยส่งหลักฐานกลับไปให้งาน implementation

↗ 14

to-prototype

Prototype

สร้าง prototype ด้วย HTML, CSS และ JavaScript เพื่อช่วยตัดสินใจเรื่อง UI

↗ 15

edit-prototype

Prototype

ปรับเฉพาะส่วนของ prototype ตาม revision ที่ระบุ

↗ 16

spec-with-prototype

Prototype

นำพฤติกรรมของ prototype ที่ยอมรับแล้วมาปรับให้ตรงกับ spec

↗ 17

unit-test

Verification

ตรวจพฤติกรรมแยกส่วนด้วย test runner ของ repo และ expected results ที่เป็นอิสระ

↗ 18

integration-test

Verification

ตรวจการทำงานร่วมกันของ component และ service โดยไม่ mock จนขอบเขตจริงหายไป

↗ 19

e2e-test

Verification

ตรวจ user journey สำคัญที่อยู่ในขอบเขต task ด้วยระบบทดสอบของโปรเจกต์
