# SPEC-010: UI design craft

- Status: done
- Requirement: [Requirement](../requirement.md#current-capability-ui-design)
- Context: [Context](../../CONTEXT.md#current-capability-ui-design)

## Problem and outcome

The existing UI guidance prevents obvious clutter but leaves visual direction,
typographic hierarchy, spatial rhythm, and critique too implicit. The user
requested studying pbakaus/impeccable and improving this pack's UI results.
Make those decisions actionable without importing another workflow or installer.

## Scope

Revise `ui-design` and add focused craft/critique references. Integrate their
use with the existing prototype and implementation parents and optional design
discovery. Preserve all 23 identifiers, source ownership, confirmed design,
behavior, revision rules, and verification policy. Record pinned upstream
provenance and its Apache-2.0 license. No CLI, binary, hooks, dependencies,
automatic global installation, new workflow stage, or mandatory interview.

## Acceptance and verification
